# D2 Móveis — Seu Móvel

Site responsivo da **D2 Móveis Sob Medida**, desenvolvido com React + Vite e hospedado como site estático no Render.

## Experiência disponível

- Página inicial com apresentação da marca
- Catálogo visual conceitual e filtro de ambientes
- Explicação das etapas de planejamento
- Formulário para preparar uma solicitação de projeto
- Cópia do resumo e compartilhamento via WhatsApp, sem destinatário pré-configurado
- Navegação adaptada para celular, tablet e computador

## Como executar

Requer Node.js 20.19+ ou 22.12+.

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

No Render: comando de build `npm install && npm run build`, diretório publicado `dist`, branch `main`.

## Segurança, privacidade e limitações

Este é um **site público demonstrativo**, sem login, API, banco de dados ou área de gestão. Não há gravação nem transmissão de formulários para a D2; o próprio visitante copia ou compartilha o texto produzido. Sem número oficial da empresa, o atalho do WhatsApp abre uma mensagem sem destinatário definido. As ilustrações de interiores são conceituais e não representam fotografias de serviços concluídos.

A autenticação, a área privada administrativa (clientes, orçamentos, pedidos e projetos) e o armazenamento seguro exigem uma API e banco de dados protegidos. Não inserir dados reais/sensíveis antes dessa etapa.

## Referência visual

O projeto foi solicitado com base em um endereço `chatgpt.site` fornecido pelo usuário, mas esse endereço não pôde ser inspecionado na sessão de desenvolvimento. Portanto, este site é uma **aproximação inicial** da experiência desejada e não uma cópia visual verificada.
